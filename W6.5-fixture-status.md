W6.1–W6.4 are already merged. This branch adds three independent repeats per suite invocation, preserving each repeat's rows, run manifest, journal, patches and outputs under `repeat-N/`. The root table and rows are a combined statistical view. A root `--rejudge` is refused because its predictions live below `repeat-N/`; rejudge those directories individually and regenerate the combined view. The snapshot analyzer joins matrix cells by suite only when toolkit pin and suite SHA agree.

To regenerate a combined view after offline rejudging, use the same output directory that holds the repeat directories. Rejudge each completed `repeat-N/`, concatenate their updated `rows.jsonl` files in repeat order into the root, then run a plain regrade on the root. This spends no tokens and leaves each repeat's prediction artifacts and manifest intact:

```bash
set -euo pipefail
out="reports/eval/MODEL/DRIVER/ROLE/SUITE" # replace with the actual cell path
found=0
for run in "$out"/repeat-[1-3]; do
  [ -f "$run/rows.jsonl" ] || continue
  found=$((found + 1))
  node --experimental-strip-types runner/index.ts regrade --from "$run" --rejudge
done
[ "$found" -gt 0 ] || { echo "no completed repeats under $out" >&2; exit 2; }
rows_tmp="$(mktemp "${out}/rows.jsonl.XXXXXX")"
for run in "$out"/repeat-[1-3]; do
  if [ -f "$run/rows.jsonl" ]; then cat "$run/rows.jsonl"; fi
done > "$rows_tmp"
mv "$rows_tmp" "$out/rows.jsonl"
node --experimental-strip-types runner/index.ts regrade --from "$out"
```
